# Team Structure
The MARS/WARS program is about teaching students usefull skills and the application of those skill in a project setting all while remaining competiive in the events they compete. These skills can range from industrial to opertaional and will be explained  and taught to students by expirenced team members.
### Engineering
- Desgin and Fab
    * Can pick Design or Fab Focus, but each member will preform similar roles
    * Students will see though the design and fabrication of their parts
- Controls
    * Can pick Programming or Electronics Focus, but each member will preform similar roles
    * Programming portion to work on the robot that more embedded/automation based
    * Programming goes through code review work flow and learns correct git usage
    * Electronics will lear about Robotics controls (and PLCs?)
    * Learn basic about data protocols and control system (SPI, CAN, I2C, PID)

### Operations
- Bussiness and Media
    * Manage teams finances
    * Weekly newsletters during the season
    * Monthly newsletters during the offseason

- Outreach
    * Create and Lead Outreach Events to increase STEAM awareness
    * Organize Community Involvment Events to incresae local awareness for MARS/WARS

- Strategy and Scouting
    * Programming portion to work scouting on the app thats more web based
    * Develop game strategy and work on mesureable and helpfull robot metrics to record for match planning and alliance selection
